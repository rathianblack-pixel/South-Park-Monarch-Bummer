TEXTURE WORKFLOW

Replace an image with a new file using the same filename, then refresh the game.
Keep the same general aspect ratio and transparent background for sprites.

Folders:
- Maps: village, overworld, area, and interior backgrounds
- Monsters: enemy sprites
- NPCs: priest, merchant, blacksmith, and other characters
- Buildings: facility art
- Player: base player sprites
- Player/Equipment: weapons, focuses, and wearable pieces
- Player/Armor: armor set sprites
- UI: codex, combat cards, and endgame art

Use a local HTTP server for reliable browser loading.
